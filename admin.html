System Settings

  • Student records are stored in a local SQLite database inside data/school.db.
  • Uploaded student and website images are stored in uploads.
  • Before hosting, set a strong ADMIN_PASSWORD and SESSION_SECRET in .env.
  • For SMS, configure TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN and TWILIO_FROM_NUMBER.
  • Back up the data and uploads folders regularly.

Important: This dashboard is designed so routine school updates can be done by staff without changing source code.
